# MintMuse AI

**AI-generated art, music & NFTs — in your hands.**  
MintMuse AI empowers artists, collectors, and creators to effortlessly generate stunning visual art using OpenAI, with built-in support for NFT minting and sharing.

---

## Features

- **Image Generation** using ChatGPT / OpenAI DALL·E
- **Live Preview** before minting
- **Wallet Connection** (Metamask support)
- **NFT Minting** via Thirdweb (or your chosen provider)
- **Gallery** of recent mints
- **User-Owned API Key System** — no costs passed to MintMuse owner
