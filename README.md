# MintMuse AI

**AI-generated art, music & NFTs — in your hands.**  
MintMuse AI is a creator-first platform that empowers artists to easily generate AI-powered images, preview them, and mint them as NFTs. Built for scalability and simplicity, it lets users connect their own OpenAI API key and start creating with no upfront cost to you as the developer.

---

## Features

- **Image Generation with OpenAI (DALL·E)**
- **User-Supplied API Keys (No Server Cost)**
- **Preview Before You Mint**
- **Optional Wallet Connection for NFT Minting**
- **Gallery of Recent Creations**
- **Built with React + Vite for Speed**
